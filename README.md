# SoundRebel

SoundRebel — это современный аудиоплеер для Android, разработанный с целью обеспечения оригинального, не подвергнутого цензуре песням. В условиях, когда крупные стриминговые платформы все чаще применяют политику принудительного "заглушения" обсценной лексики даже в композициях с маркировкой "Explicit", данное приложение гарантирует воспроизведение треков в их исходном, задуманном автором виде.

## Основная концепция

Многие популярные стриминговые сервисы внедряют автоматическое редактирование аудиопотока, вырезая или заглушая фрагменты слов, что нарушает ритмический рисунок и атмосферу композиций.

Решение SoundRebel базируется на встроенном алгоритме детекции цензуры (Censorship Detection Algorithm). Система анализирует поступающие треки и, при обнаружении платформенных ограничений, в фоновом режиме извлекает оригинальный аудиопоток из альтернативных источников (таких как SoundCloud). Подмена происходит незаметно для пользователя.

## Ключевые возможности

*   **Smart Uncensored Fallback**: Автоматический алгоритм обхода цензуры платформы, осуществляющий поиск и маршрутизацию оригинального аудиопотока.
*   **Force Uncensored Override**: Функция ручного принудительного поиска исходного трека без цензуры в качестве страхующего механизма для алгоритма.
*   **Offline Mode**: Поддержка локального кэширования для сохранения извлеченных оригинальных аудиодорожек и последующего прослушивания без доступа к сети.
*   **Бесшовная интеграция метаданных**: Объединение лицензионных метаданных (обложки, альбомы, исполнители) основного источника с "сырым" аудиопотоком.
*   **Современный интерфейс**: UI разработан на основе декларативного подхода с использованием Jetpack Compose и строго следует компонентам Material Design 3 (включая Edge-to-Edge верстку).

## Технологический стек

*   **Язык разработки**: Kotlin
*   **UI-фреймворк**: Jetpack Compose (Material 3)
*   **Архитектурные паттерны**: Clean Architecture + MVVM
*   **СУБД**: Room (локальная персистентность)
*   **Работа с сетью**: Retrofit2 + Moshi
*   **Медиа-движок**: AndroidX Media3 (ExoPlayer) для стабильного фонового воспроизведения и управления аудиофокусом

## Особенности реализации алгоритма детекции

В основе работы модуля `CensorDetector` лежит эвристический анализ, опирающийся на несколько ключевых метрик:
1.  **Анализ синтаксиса текстов**: Проверка получаемых текстов песен на наличие скрытых или замаскированных символов (например, массовое использование астерисков `***` в корнях слов), что является прямым индикатором цензуры.
2.  **Словарные фильтры и списки исключений**: Сверка с предустановленными и динамическими словарями, а также валидация по конкретным артистам и релизам, чьи работы систематически подвергаются платформенной модерации.
3.  **Нечеткий поиск (Fuzzy Matching)**: В случае необходимости агрегации трека со сторонних площадок применяется алгоритм нечеткого поиска (`FuzzyMatcher`), который сопоставляет длительность, названия и наличие маркеров типа "uncensored" / "explicit" для максимально точного соответствия оригинальному треку.
